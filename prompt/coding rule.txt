Coding 작업 수행 간 엄수 규칙
- 작성 간 모든 코드는 'from importation 문 -> 1줄 공백 -> import importation 문 -> 4줄 공백 -> 본문 -> 4줄 공백 -> 현 파일 직접실행 문' 규칙을 따를 것
- 작성 간 모든 코드는 가능한 모든 경우에 대해 그 자료형을 반드시 명기할 것
- 작성 간 모든 필요 패키지는 프로젝트 루트 위치 내 requirements.txt 내 버전과 함께 명기돼야 함
- 작성 간 금번의 모든 코드 생성(변경)에 대해 상세한 한국어 설명을 프로젝트 루트 위치 내 temp/update.txt라는 내용으로 파일 생성 및 내용 작성할 것
